# AlgoTri

Visualiseur interactif d'algorithmes de tri dans le terminal.

## Stack

- C17 — GCC
- ncursesw
- Make

## Prérequis

Arch Linux :

```bash
sudo pacman -S gcc make ncurses
```

Debian / Ubuntu :

```bash
sudo apt-get install -y build-essential libncurses-dev
```

## Lancer le projet

```bash
make
make run
```
